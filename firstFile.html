🚀 Práctica de Git & GitHub

Flujo Básico de Trabajo

Comandos Esenciales

  • git clone <url-del-repositorio> Descarga una copia local del repositorio remoto.
  • git status Muestra el estado actual del árbol de trabajo (archivos modificados o nuevos).
  • git add index.html Prepara los cambios en el archivo para el commit (Staging Area).
  • git commit -m "feat: mi primera contribución" Guarda la instantánea de los cambios con un mensaje descriptivo.
  • git push origin main Sube los commits locales al repositorio en GitHub.
